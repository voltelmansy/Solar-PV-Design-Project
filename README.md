# Solar-PV-Design-Project
# 🌞 Off-Grid Solar PV System Design

A complete engineering design of an Off-Grid Solar Photovoltaic system for a small residential house, ensuring 24/7 energy autonomy using solar generation and battery storage.

---

## 📌 Project Overview
This project simulates and designs a **standalone solar PV system** capable of powering a residential home without grid dependency.

It includes:
- Load analysis
- PV sizing
- Battery bank design
- Inverter & controller selection
- System architecture diagrams
- Energy performance charts

---

## ☀️ Solar PV System Design

- Location: Cairo, Egypt  
- Peak Sun Hours: 5.5 hours/day  
- System Efficiency: 75%  

### 🔆 PV Array
- Required: ~790 W
- Selected: **1.1 kWp (2 × 550W panels)**

---

## 🔋 Battery System

- Voltage: 24V  
- Capacity: 200Ah  
- Autonomy: 1 day backup  

---

## ⚙️ System Components

- ☀️ PV Panels: 1100 Wp
- 🔋 Battery Bank: 24V 200Ah
- ⚙️ MPPT Controller: 60A
- 🔌 Inverter: 2 kW Pure Sine Wave
